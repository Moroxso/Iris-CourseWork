# Проверка готовности Iris-CourseWork

Пункты отмечаются только по фактическим результатам на целевом ПК.

- [ ] Клон находится на согласованном коммите. После установки
  `git status --short` не показывает изменений `pyproject.toml` или `uv.lock`.
- [ ] CPython 3.12; пробное вычисление PyTorch на CPU успешно; CLI выдаёт
  справку; целевые тесты из инструкции проходят без загрузки модели.
- [ ] Все семь файлов фиксированного снимка Qwen доступны локально.
- [ ] Есть снимок моста после 6-го шага; `coursework_offline_kit.py verify`
  завершился кодом 0. Число проверенных файлов берётся из его вывода.
- [ ] Консоль сообщает «Готово», принимает запрос и возвращает текст.
  Записан фактический ответ; ожидаемый текст контрольного примера — «кедр».
- [ ] Браузер показывает схему: 8 модулей, 8 слотов, 3 цикла, 2 записи
  за цикл. В первом цикле нет чтения занятых слотов. В третьем доступны
  чтение выбранным модулем и раскрытие двух векторов по 256 координат
  для каждой записи. Таблица входа генератора содержит 8 строк.
- [ ] После `/exit` локальный сервер закрывается; сохранённый `viewer.html`
  продолжает открываться. Конкретный каталог сеанса и команда повторного
  запуска переданы оператору.

Отказ модели дать верный ответ отмечается отдельно от ошибки запуска.
Если браузер на целевом ПК недоступен для автоматизации, проверка интерфейса
остаётся ручной и не отмечается выполненной заранее.
