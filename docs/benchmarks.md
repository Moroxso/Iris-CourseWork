# Учебные проверки Qwen и Iris

Сценарий `scripts/coursework_workspace_comparison.py` сравнивает три
режима: Qwen без вставки, Iris с пустыми слотами перед обученным мостом
и полный Iris. Во всех режимах одинаковы запрос, шаблон диалога, веса
Qwen, жадное декодирование и предел в 192 новых токена. Очистка слотов
не убирает мост и позиции вставки; она меняет только состояние на входе
моста. Изменение ответа не равнозначно повышению точности.

| Набор | Полный профиль | Пробный профиль |
| --- | ---: | ---: |
| `multilingual` | 96 | 12 |
| `math-code` | 32 | 8 |

Многоязычный набор содержит русский, английский и упрощённый китайский.
Есть короткие и длинные задания на поиск, связывание фактов, порядок
событий, извлечение полей JSON и выбор списка из 24 кодов. Длину
длинных входов измеряет токенизатор после применения шаблона. Для
массивов учитывается порядок, для объектов — ожидаемые ключи и
значения; отдельно показываются полные и частичные совпадения.

В наборе по математике и Python проверяются четыре семейства
математических задач и четыре семейства коротких целочисленных функций.
Численное равенство проверяется точно, без округления; явный итог в
развёрнутом ответе отмечается отдельно от строгого формата «только число».
Ответы с кодом разбираются как синтаксическое дерево. Встроенный
проверяющий интерпретирует только ограниченные целочисленные операции,
условия и вызовы `abs`, `min`, `max`. Не запускаются произвольные
программы, импорты и циклы. Неподдерживаемый синтаксис отличается
в отчёте от неверного результата на проверочном входе.

## Запуск

Используйте `$python`, `$snapshot`, `$checkpoint` и `$manifest` из
[инструкции установки](../INSTALL.md). После обновления исходников
соберите новый локальный комплект, если прежний больше не проходит проверку.

```powershell
$script = 'scripts/coursework_workspace_comparison.py'
& $python -I -B $script --snapshot $snapshot --prepare-only --out (Join-Path $PWD 'artifacts/prepare-multilingual')
& $python -I -B $script --suite math-code --snapshot $snapshot --checkpoint $checkpoint --manifest $manifest --profile smoke --out (Join-Path $PWD 'artifacts/math-code-smoke')
```

Выберите новый выходной каталог для каждого запуска. Без `--profile smoke`
выполняется полный профиль; он может занять заметно больше времени на
центральном процессоре. С `--prepare-only` проверяется токенизация без
загрузки весов. Откройте `index.html` для просмотра, `report.json` для
исходных результатов и `observations.jsonl` для наблюдений по мере
выполнения. Эти небольшие синтетические проверки описывают поведение
на конкретных задачах, а не общее качество модели.
